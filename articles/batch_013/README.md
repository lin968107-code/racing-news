# 第十三批文章目录（batch_013）

此目录用于下一批100篇 Markdown 文章。

## 上传方法

进入本目录，点击 **Add file → Upload files**，只上传该批文章的100个 `.md` 文件，不要把 `articles` 文件夹再次拖进去。

## 统一格式

- 文章正文继续保留：名爵168极速赛车、飞天BV极速赛车、168极速赛车群、房间号998788、微Q：1177368。
- 文件名采用短格式，例如 `001-名爵168-飞天BV.md`。
- 本目录中的统一黑金封面路径必须是 `../../images/unified-cover.png`。
- 相关文章链接应该指向 `https://github.com/lin968107-code/racing-news/blob/main/articles/batch_013/文件名.md`。
- 原有 `articles/` 文件保持原位，不改变已经公开的旧链接。

## 说明

将来批次可新建 `articles/batch_014/`、`articles/batch_015/` 等目录。文件的真实发布时间以 GitHub 提交时间为准，而不是标题中的编排日期。
