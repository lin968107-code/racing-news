# 已审核文章队列

只有人工检查并确认可以公开发布的 Markdown 文件才放在这里。每天北京时间08:00的 GitHub Actions 会按文件名顺序最多发布100篇，不足100篇则按实际合格数量发布；不会生成内容凑数。

每篇需以 `# 标题` 开头，正文至少600个汉字，包含“名爵168极速赛车”“飞天BV极速赛车”“房间号998788”“微Q”等字样。必须有独立主题，保证信息准确、无违法或不实承诺。图片会统一插入黑金封面，不要自行嵌入其他图片。文件名应唯一。旧标题和完全重复的文章将跳过。

发布后文件进入 `articles/daily_YYYYMMDD/`；源稿从本队列移走。相关文章链接自动插入，指向同一天实际发布的文章。

请勿将未审核草稿批量放入此目录；已上传到旧 `articles/` 的文章也不会重复发布。
